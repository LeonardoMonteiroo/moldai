# Data layer: pure logic + thin repositories

> For the why behind these rules, see [`../decisions/data-layer.md`](../decisions/data-layer.md).
> For universal, cross-cutting rules, see the root [`CLAUDE.md`](../../CLAUDE.md).

- `Pattern` (Prisma) has its own cuid `id` with `userId` as a plain indexed foreign key — many patterns per account. Each row holds a `PatternState` JSON blob (pattern, chat, active conflict — no credits).
- Editor-state logic is pure and DB-free in `lib/editor/state.ts` (`seedPatternState`, `addMessage`, `bumpVersion`, `setConflict`, `applyGarmentSpec`, `refitSleeve`, `applySizes`), unit-tested without a live DB.
- `lib/db/pattern.ts` is the only layer touching Prisma for patterns. Every function is scoped to `(patternId, userId)` and returns `null`/`false` — never throws, never leaks whether the row exists — when the pattern is missing or not owned; routes turn that into `patternNotFound()` (404).
- `withPattern(patternId, userId, fn)` runs load→mutate→save in an interactive transaction with a row lock (`SELECT … FOR UPDATE WHERE id = $1 AND userId = $2`), built from the exported primitives `lockPattern`/`savePattern` so `withPatternAndWallet` reuses the same SQL (see [`billing.md`](billing.md)). The transaction timeout is raised to 30s because the AI call runs inside it.
- CRUD: `loadPattern` (ownership-scoped read), `createPattern` (new blank pattern), `listPatternsForUser` (projects `{id, name, garmentType, updatedAt, thumbnailSvg}`; the thumbnail is server-built by `lib/editor/thumbnail.ts`'s `buildThumbnailSvg` from the already-drafted pieces — no redraft, no AI call), `renamePattern`, `deletePattern`. There is no pattern-reset endpoint — delete + create replaces it.
- Every `app/api/*` route is gated by `requireUser()` (`lib/auth/guard.ts`) — 401 without a session, with the small set of deliberate exceptions listed in [`api-routes.md`](api-routes.md). Auth logic is likewise pure/DB-free (`lib/auth/authorize.ts`, `lib/auth/session.ts`); the NextAuth config is `auth.ts` (`trustHost: true` for self-hosted/prod).
- **`Pattern` has no `savedAgo`.** The wire carries `updatedAt` instead and the editor renders `relativeTime(t, updatedAt)`. The final shape is **`PatternRecord extends Pattern { updatedAt: string }`** — the wire shape used by `EditorState.pattern` and the editor store — the existing `SizeChartRecord extends SizeChartData` precedent. `loadPattern` returns `{state, updatedAt}`; `lockPattern` deliberately does **not**, because `savePattern` sets `updatedAt = now()` inside the same transaction, so a mutating route's own `now` already _is_ the row's timestamp. Old blobs keep an inert `savedAgo` key that nothing reads — no reset migration needed.
