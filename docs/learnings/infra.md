## 2026-09-04 — `Stop` runs a ~200s verification sweep, not an instant exit

- **Symptom** — a session appears to hang for a while right after the model's last
  message, with no visible tool call in progress.
- **What's actually true** — `.claude/settings.json`'s `Stop` hook runs
  `.claude/hooks/verify-on-stop.mjs` (timeout 200s), which re-runs `vitest run` and
  the scoped `eslint app lib components` sweep whenever tracked source under
  `app`/`lib`/`components` changed, and blocks the stop (handing the real failure
  text back) if either fails. See the hook's own header comment for why those exact
  commands and not `npm run lint`/`npm run build`.
- **Do this instead** — don't re-run the test/lint sweep yourself right before
  stopping; the hook already does it. If a stop is rejected, read the hook's stdout
  for the actual failing test/lint output rather than re-guessing what broke.

## 2026-09-04 — writes to `.env*` and root `AGENTS.md` are hard-denied

- **Symptom** — an `Edit`/`Write` to `.env.local` (or any `.env*` besides
  `.env.example`/`.env.sample`) or to the repo-root `AGENTS.md` is silently rejected
  by a permission-denial, not by a normal tool error.
- **What's actually true** — `.claude/hooks/guard-paths.mjs:179-188` is a
  `PreToolUse` hook (matcher `Edit|Write`) that denies both on sight: real secrets
  live in `.env.local` and can't be recovered from git if overwritten, and
  `AGENTS.md` is regenerated by `next dev` (`node_modules/next/dist/server/lib/generate-agent-files.js`)
  so a hand-edit is thrown away and reappears as an uncommitted diff.
- **Do this instead** — for env vars, ask the user to edit `.env.local` themselves,
  or create/edit `.env.example` (not blocked) to document a new variable name. For
  `AGENTS.md`, edit `CLAUDE.md` instead — it's the source of truth and already
  `@`-references `AGENTS.md`.
