# Data layer: pure logic + thin repositories

> This is the _why_. For the operative rule, see [`../architecture/data-layer.md`](../architecture/data-layer.md).
> For universal, cross-cutting rules, see the root [`CLAUDE.md`](../../CLAUDE.md).

- **`Pattern` used to have a `savedAgo` field, and it was a live bug, not a stylistic choice to remove.** It was persisted pt-BR display text that nothing recomputed — the editor header claimed "salvo agora" indefinitely, including after a reload, independent of whatever else prompted the sweep that found it. The fix couldn't just delete the field and stop: **leave it out and `relativeTime` falls through to render the literal string "Invalid Date"** instead of compiling to a value that's simply never missing — which is why the final shape widens `Pattern` into `PatternRecord extends Pattern { updatedAt: string }` (the `SizeChartRecord extends SizeChartData` precedent) rather than just adding a field to `Pattern` itself.
- **No reset migration was needed, and that was a deliberate call, not an oversight.** Old blobs keep an inert `savedAgo` key that nothing reads — the cheap direction of a blob change. Contrast this with the PT→EN wire-shape rename mentioned under the language-boundary convention (`docs/architecture/conventions.md`): that one wiped every persisted pattern blob because renaming a wire-carried key/value is destructive, where merely adding a new key and ignoring an old one is not.
- `lockPattern` deliberately does **not** widen to return `updatedAt` the way `loadPattern` does, because `savePattern` sets `updatedAt = now()` inside the same transaction, so a mutating route's own `now` already _is_ the row's timestamp — returning it from `lockPattern` too would be a second copy of a fact the caller already has.
