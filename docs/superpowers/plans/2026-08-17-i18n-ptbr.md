# Subsistema 3 — i18n (next-intl, single-locale pt-BR) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Externalizar o chrome de UI dos componentes/app para um catálogo `next-intl` (locale único pt-BR), sem mudar nenhum texto visível nem comportamento.

**Architecture:** Setup do `next-intl` sem i18n routing (locale fixo pt-BR) = espinha serial (provider+config antes de qualquer `useTranslations`). Depois, extração incremental por grupos de componentes, cada um adicionando seu namespace ao `messages/pt-BR.json` compartilhado e fechando com o gate verde. Serial (catálogo é arquivo compartilhado → evita conflito de merge).

**Tech Stack:** next-intl 4.13.7 (peer `next ^16` + `react ^19` → compatível), Next 16 App Router, TypeScript, Vitest.

## Global Constraints

- **Zero mudança de texto visível ou comportamento.** Extração 1:1: cada literal pt-BR de UI vira `t("chave")` com o MESMO valor no catálogo. A UI continua idêntica.
- **Escopo thin — só chrome de UI** em `components/editor/*.tsx`, `app/login/page.tsx`, `app/page.tsx`: labels de botão, abas, empty states, headers, aria-labels, placeholders, chips estáticos, notas "em breve".
- **FORA (não tocar):** strings geradas na `lib/` (drafters `name`/`detailRows`, `state.ts` `ConflictInfo.description`/`suggestion`) = i18n Fase 2; o `assistantMessage` da IA; o system prompt. Esses seguem pt-BR literais.
- **Chaves do catálogo em inglês, valores em pt-BR** (coerente com a fronteira do subsistema 2). Namespace = nome do componente.
- **Client vs server:** todo o editor roda sob `EditorShell` (`"use client"`) → usar o hook `useTranslations("NS")` nos componentes do editor. `app/page.tsx` e `app/layout.tsx` são **server** → se tiverem texto, usar `await getTranslations("NS")`. `app/login/page.tsx` é client → `useTranslations`.
- Typecheck = `npm run build` (NUNCA `tsc --noEmit`). Lint escopado `eslint app lib components`. Gate do subsistema 1 ativo (pre-commit formata). Instalar deps com `--legacy-peer-deps`.
- Model id `claude-sonnet-5` intacto; segredos nunca impressos. Commits terminam com `Co-Authored-By: Claude Opus 4.8 (1M context) <noreply@anthropic.com>`.
- **Catálogo compartilhado:** cada task de extração adiciona SEU(S) namespace(s) ao `messages/pt-BR.json` — não reescrever/reordenar namespaces de outras tasks.
